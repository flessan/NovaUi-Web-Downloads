How it works
  1. Install Manually first - download the Stable pack from this site and place it in geode/config/geode.texture-loader/packs.
  2. Add the Extension - install the Updater for Nova UI extension on top.
  3. Stay updated automatically - the extension checks api.github.com/repos/DANZGAME-GD/NovaUI-exten/releases and installs new releases without manual steps.
Responses are cached for 10 minutes to avoid rate limits. If GitHub is slow or unavailable, you'll see cached data with a refresh option. Supports keyboard navigation, focus rings, and works in both light and dark themes.
