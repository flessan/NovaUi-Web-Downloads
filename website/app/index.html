What is Geode?

Geode is an open-source mod loader for Geometry Dash that lets you install mods, texture packs and custom content without modifying the original game files. Built by the community, Geode has become the standard for GD modding, replacing older methods that risked breaking the game.

Safe & non-invasive
Doesn't modify game files. Can be uninstalled at any time without a trace.
Install once, done
Install Geode, then download mods and packs - they activate instantly. No complex setup.
Large community
Thousands of mods and packs from the worldwide GD community on the Geode hub.
Open source
The source code is public on GitHub - transparent and auditable by anyone.

Geode packs vs the old method

Why are Geode texture packs better than the old approach of replacing files in the Resources folder?

Old method

  • Overwrites original game files
  • Breaks whenever GD updates
  • Requires manual backups
  • Can't be toggled on or off
  • Packs conflict with each other

Geode packs

  • Separate files - the game stays safe
  • Unaffected by game updates
  • Automatically isolated
  • Toggle on and off instantly
  • Minimal conflicts
FAQ

Frequently asked questions

Can Geode get me banned?

No. Geode only modifies the game locally on your machine. As long as you don't use hacks or cheats - speedhack, noclip, star hack - you won't be banned. Texture packs are completely safe because they only change the visual appearance without affecting gameplay.

Can I completely uninstall Geode?

Yes, very easily. Delete the geode/ folder in your Geometry Dash directory, then in Steam right-click GD → Properties → Installed Files → Verify integrity of game files. The game returns to its original state completely, as if Geode had never been installed.

What's the difference between Geode packs and old packs?

Geode packs don't overwrite original game files. All pack files live separately in the geode/mods/ folder. You can toggle them on and off at any time without restarting, no manual backups are needed, and they don't break when the game updates. Old packs that replace files in the Resources folder are no longer recommended.

Can I request a texture pack?

Yes. Contact the pack creator through GitHub or their social media. For DANZGAME packs, reach out via the GitHub repository linked on the pack download page.

Are all the packs here free?

Yes, 100% free. Every texture pack on this site can be downloaded at no cost. Geode itself is open-source and free too. No paywalls, no ads, no hidden fees.

How do I create my own texture pack?

Create a folder with a valid texture-pack structure including pack.json, replace the sprite textures you want, and follow the format specified by the Geode SDK. Full documentation is available at Geode Texture Loader. Texture unpackers can help you extract the original GD sprites.
